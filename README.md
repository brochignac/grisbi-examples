# grisbi-examples:

## English:

In this folder, you will find the file 'Example_3.0-en.gsb`, which will help you familiarise yourself with Grisbi.

Simply:

* either click on the file, which will open in Grisbi,

* or open Grisbi and click on ‘File - Open (Ctrl+O)’ or the ‘Open’ button, then select the file from your file explorer.

You will also find an example of a depreciation schedule provided by Grisbi.

## Français:

Vous trouverez dans ce dossier le fichier "Example_3.0-fr.gsb" qui vous permettra de vous familiariser avec Grisbi.

Il vous suffit:

* soit de cliquer sur le fichier qui s'ouvrira dans Grisbi,

* soit d'ouvrir Grisbi et de cliquer sur "Fichier - Ouvrir (Ctrl+O)" ou sur le bouton "Ouvrir" et de sélectionner le fichier dans votre explorateur de fichiers.

Vous y trouverait également un exemple de tableau d'amortissement fourni par Grisbi.

## Deutsche:

In diesem Ordner finden Sie die Datei „Example_3.0-de.gsb“, mit der Sie sich mit Grisbi vertraut machen können.

Sie müssen lediglich:

* entweder auf die Datei klicken, die sich dann in Grisbi öffnet,

* oder Grisbi öffnen und auf „Datei – Öffnen (Strg+O)“ oder auf die Schaltfläche „Öffnen“ klicken und die Datei in Ihrem Dateimanager auswählen.

Außerdem finden Sie dort ein von Grisbi bereitgestelltes Beispiel für einen Tilgungsplan.
